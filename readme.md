# Neural Network from Scratch – Spiral Data Classification

This project implements a fully connected neural network from scratch using **NumPy**. It demonstrates classification of 2D spiral data and visualizes decision boundaries, training losses, and network predictions.

## Features

- Fully connected feedforward neural networks  
- Manual forward and backward propagation  
- Custom activation functions (`LeakyReLU`, `sigmoid`)  
- Binary classification with cross-entropy loss  
- Training with configurable learning rate, epochs, and convergence threshold  
- Visualization of decision boundaries and predictions  
- Save and load trained networks
